📄 O que é HTML?

HTML = HyperText Markup Language — Linguagem de Marcação de Hipertexto. Ela dá estrutura à página: títulos, textos, imagens e links. É o esqueleto de todo site.

Principais elementos:

  • <html> — envolve todo o documento
  • <head> — informações técnicas, título e estilo
  • <body> — todo o conteúdo que aparece na tela
  • <h1> a <h6> — títulos em níveis
  • <p> — parágrafos de texto
  • <img> — imagens
  • <a> — links

🎨 O que é CSS?

CSS = Cascading Style Sheets — Folhas de Estilo em Cascata. Cuida da aparência: cores, fontes, tamanhos, espaços e organização visual. Separa o conteúdo do design.

O que ele faz:

  • Define cores de texto e fundo
  • Escolhe fontes e tamanhos
  • Controla espaços: padding (interno) e margin (externo)
  • Coloca bordas, sombras e cantos arredondados
  • Organiza elementos na tela
  • Deixa o site bonito no celular e no computador

⚡ O que é JavaScript?

É uma linguagem de programação que traz interatividade. Enquanto HTML é estrutura e CSS é visual, JavaScript é a ação: responder a cliques, mostrar mensagens, calcular valores e mudar conteúdo sem recarregar a página.

Conceitos básicos:

  • Responde a ações do usuário: clique, digitação
  • Usa variáveis para guardar informações
  • Executa cálculos e toma decisões
  • Transforma uma página estática em algo dinâmico

💻 Desenvolvimento de Sistemas

É o processo completo de criar soluções digitais. Não é só escrever código: é entender o problema, planejar, construir, testar e manter.

Etapas de um projeto:

  • 🔹 Compreender a necessidade
  • 🔹 Planejar como será a estrutura
  • 🔹 Criar o Front-end (o que o usuário vê — HTML+CSS+JS)
  • 🔹 Criar o Back-end (processamento e dados)
  • 🔹 Testar e corrigir erros
  • 🔹 Publicar e atualizar

Por que essas três juntas?

HTML organiza, CSS embeleza, JavaScript dá vida. Juntas formam a base de todos os sites que você visita todos os dias. Aprender cada uma bem é o primeiro passo para criar suas próprias soluções.
